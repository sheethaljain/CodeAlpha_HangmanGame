# CodeAlpha Hangman Game

A simple, interactive, text-based Hangman game developed in Python as part of my CodeAlpha Python Programming Internship.

## Project Overview

The game randomly selects a word from a predefined list. The player guesses one letter at a time to reveal the hidden word.

The player can make up to six incorrect guesses before the game ends.

## Features
- Five predefined words
- Random word selection
- Six incorrect guesses allowed
- Displays correctly guessed letters
- Prevents repeated guesses
- Validates user input
- Displays win or loss messages

## Technologies Used
- Python 3
- random module
- VS Code

## How to Run
1. Install Python 3.
2. Download or clone this repository.
3. Open the project folder in a terminal.
4. Run:

   python hangman.py
